## Temuan

### HIGH (Hard Gate)

**1. R-25 Kontras teks gagal WCAG AA**
`text-stone-400` (#a8a29e, sekitar 2.5:1 di atas putih) dipakai untuk teks yang harus dibaca: [onboarding/page.tsx](../src/app/onboarding/page.tsx) L100 dan L125, [new-card-form.tsx](../src/app/admin/cards/new/new-card-form.tsx) L182, [card-manager.tsx](../src/app/admin/cards/[id]/card-manager.tsx) L407 dan L451, [customers-view.tsx](../src/app/admin/customers/customers-view.tsx) L143 dan L169, [qr-dialog.tsx](../src/components/qr-dialog.tsx) L197. Link `text-amber-600` ukuran `text-xs` di atas putih (sekitar 3.2:1) di [login](../src/app/(auth)/login/page.tsx) L113 dan register L120.
Perbaikan: teks sekunder ke `slate-600`/`slate-500`, link ke biru tinta.

**2. R-32 / R-39 Dialog tidak bisa ditutup dengan Escape**
Modal QR pelanggan di [customer-card-view.tsx](../src/app/c/[token]/customer-card-view.tsx) L124 serta dua dialog konfirmasi (batal stempel, tukar hadiah) di [card-manager.tsx](../src/app/admin/cards/[id]/card-manager.tsx) L473 dan L511: tanpa handler Escape, tanpa `aria-labelledby`, fokus tidak dipindah ke dialog. `qr-dialog.tsx` sudah benar dan bisa jadi acuan.

**3. R-27 Tidak ada loading state dan error boundary**
Tidak ada `loading.tsx` atau `error.tsx` di seluruh `src/app`. Semua halaman admin dan `/c/[token]` mengambil data di server, jadi selama fetch layar diam tanpa indikator, dan error Supabase tidak punya tampilan. Gagal salin tautan di customer-card-view (L37 `catch {}`) juga diam tanpa umpan balik.
Perbaikan: `loading.tsx` per segmen yang menyebut apa yang dimuat, `error.tsx` dengan penyebab dan tombol coba lagi, pesan gagal salin.

**4. R-38 / R-39 Splash "opening" menampilkan progres palsu dan tidak bisa dilewati**
[brand-intro.tsx](../src/components/brand-intro.tsx): overlay layar penuh 2.5 detik saat kunjungan pertama, progress bar "Memuat aplikasi..." padahal tidak ada yang dimuat (progres dari timer). Tidak ada tombol lewati atau Escape, shimmer berputar tanpa henti (L74). Tombol "Putar Ulang Opening" muncul 3 kali di landing (navbar L61, hero L107, footer L250).
Perbaikan yang diusulkan: hapus splash dan ketiga tombol replay. Kalau ingin tetap ada, jadikan bisa dilewati, tanpa progress bar palsu, dan satu tombol replay saja.

**5. R-03 Target sentuh di bawah 44px dan navbar landing berisiko overflow di 360px**
Tombol `size="sm"` (h-8, 32px) di navbar landing dan admin, tombol replay `py-1.5 text-xs` (sekitar 28px), chip filter status di [cards-view.tsx](../src/app/admin/cards/cards-view.tsx) L76 sampai L102, tombol simulator di [hero-card-simulator.tsx](../src/components/hero-card-simulator.tsx), tab admin `py-1.5`. Navbar landing berisi logo + "Putar Ulang Opening" + Masuk + Daftar Usaha; estimasi lebarnya melebihi 360px (belum diukur di browser, perlu dicek saat perbaikan).
Perbaikan: minimal `h-11` untuk kontrol utama di mobile, hapus tombol replay dari navbar.

### MEDIUM (Purpose-Gate)

**6. R-01 / R-29 Palet kuning-oranye sebagai default dan tidak konsisten**
Amber dipakai di sekitar 120 tempat: tombol utama, ikon, badge, tab aktif, progress bar, selection, ring fokus. `Button` default memakai `orange-600` ([button.tsx](../src/components/ui/button.tsx) L17) sementara hampir semua page menimpanya dengan `amber-600`, jadi ada dua warna primer. `Input` memakai ring `orange-500`. Token di [globals.css](../src/app/globals.css) (`--card`, `--border`, `--ring`) didefinisikan tapi tidak dipakai, warna di-hardcode per file (`dark:bg-[#0c0d0e]` berulang).
Perbaikan: token slate + biru tinta di `globals.css`, `Button` dan `Input` memakai token, hapus override warna per page.

**7. R-01 / R-07 Radial orb kuning di belakang konten**
Glow radial amber + `blur-3xl` di landing (L90), login (L25), register (L25), onboarding (L50), brand-intro (L58), dan halaman pelanggan (L79). Teks H1 landing memakai gradient amber (L119).
Perbaikan: hapus semua orb dan gradient teks. Fokus visual dipegang kartu loyalitas.

**8. R-13 / R-19 Pulse tanpa henti dengan glow**
`animate-gentle-pulse` (loop tak terbatas + glow amber) di tombol Tukar Hadiah ([card-manager.tsx](../src/app/admin/cards/[id]/card-manager.tsx) L364), banner selesai di [loyalty-card.tsx](../src/components/loyalty-card.tsx) L86, ikon di [admin/page.tsx](../src/app/admin/page.tsx) L130. `animate-card-float` didefinisikan tapi tidak dipakai.
Perbaikan: hapus loop. Status "siap tukar" ditandai warna dan label, bukan gerakan. Pertahankan `stampPop` (gerakan satu kali saat stempel ditambah, ada tujuannya).

**9. R-10 Glassmorphism melebihi batas dosis**
`backdrop-blur` di navbar landing, navbar admin, kartu login/register/onboarding, overlay tiga dialog, dan di dalam kartu loyalitas (logo, target, slot stempel).
Perbaikan: navbar dan kartu jadi solid; blur cukup di overlay modal.

**10. R-09 Eyebrow badge di atas H1 dan badge kapsul uppercase**
Pill "Kartu Loyalitas Digital Tanpa Pasang Aplikasi" + ikon ShieldCheck tepat di atas H1 landing (L101), mengulang isi subjudul. Pill uppercase "DIGITAL LOYALTY SYSTEM" di brand-intro (L86).
Perbaikan: hapus; infonya sudah ada di paragraf hero.

**11. R-04 Ikon Sparkles sebagai dekorasi**
Sparkles dipakai sebagai ikon fitur "Kustomisasi Identitas Usaha" (landing L209), label "Simulasi Interaktif", baris target di kartu loyalitas, dan brand-intro. Tidak ada hubungannya dengan kontennya.
Perbaikan: ganti ikon relevan (mis. `Palette` untuk kustomisasi, `Gift` untuk target hadiah) atau tanpa ikon.

**12. R-12 Bayangan besar di banyak komponen**
`shadow-xl`/`shadow-2xl` di kartu auth, strip CTA landing, preview pengaturan, dialog; `shadow-md`/`shadow-lg` di tombol.
Perbaikan: bayangan hanya untuk kartu loyalitas (objek "fisik") dan dialog. Tombol dan kartu form datar dengan border.

**13. R-05 / R-14 Landing mengikuti template**
Urutan hero + 3 kartu fitur identik (ikon dalam kotak, judul, deskripsi, "Tiga keunggulan utama") + kotak CTA gelap bergradient + footer.
Perbaikan: ganti 3 kartu dengan alur nyata produk yang memang ada di app: kasir scan QR, beri stempel dengan catatan nota, pelanggan menukar hadiah, owner melihat riwayat audit. Disusun sebagai daftar bernomor berdampingan dengan kartu demo, bukan grid kartu. Strip CTA jadi satu baris sederhana.

**14. R-08 Panah dekoratif dan menyesatkan**
`ArrowRight` di CTA hero; `ArrowUpRight` (makna: tautan eksternal) di tiga pintasan internal admin ([admin/page.tsx](../src/app/admin/page.tsx) L172, L185, L198).
Perbaikan: hapus `ArrowUpRight`; CTA hero tanpa panah.

**15. R-06 Tipografi tanpa alasan dan label uppercase ber-tracking**
`--font-geist-sans` direferensikan di `globals.css` tapi font Geist tidak pernah dimuat di [layout.tsx](../src/app/layout.tsx), jadi jatuh ke system-ui secara tidak sengaja. Label micro uppercase `tracking-wider` di kartu loyalitas ("Kartu Pelanggan Setia", "Pemegang Kartu", badge siklus).
Perbaikan: pilih satu typeface dengan alasan dan muat via `next/font` (atau sengaja system-ui dan hapus referensi Geist); label kartu jadi sentence case.

**16. Demo tanpa produk: halaman pendaftaran tanpa Syarat & Ketentuan / Kebijakan Privasi**
Landing dan register meminta pendaftaran usaha, tapi tidak ada halaman Syarat Layanan atau Kebijakan Privasi. Isi legal harus dari kamu (R-23), saya tidak akan mengarangnya.
Perbaikan: kamu kirim teksnya, atau saya buat dua halaman dengan placeholder `[TEKS LEGAL DARI PEMILIK]` yang jelas.
